Dit document beschrijft een implementatiemodel, in dit geval het implementatiemodel Landbouwgebruiksperceel. Een implementatiemodel beschrijft het datamodel van een specifieke gegevensuitwisseling. Als de uitwisseling in een groep toepassingen valt waarvoor een applicatieprofiel bestaat, houdt dit een verdere selectie van termen in of het vaststellen van bijkomende restricties of uitbreidingen voor de specifieke toepassing en/of voor het specifieke platform van de gegevensuitwisseling.

Entiteiten

Exploitatie

Beschrijving
Het uitvoeren van handelingen voor bepaalde doeleinden.
Eigenschappen
Voor deze entiteit zijn de volgende eigenschappen gedefinieerd: beslag , exploitant .

beslag Exploitatiebeslag 0..* Het beslag dat de Exploitatie legt.
exploitant Agent 1 De Agent die exploiteert.

Exploitatiebeslag

Beschrijving
Tijdelijk toe-eigenen van entiteiten bij de uitbating.
Eigenschappen
Voor deze entiteit zijn de volgende eigenschappen gedefinieerd: perceel , uri .
Eigenschap Verwacht Type Kardinaliteit Beschrijving Gebruik Codelijst
perceel Gebruiksperceel 0..* Het gebruiksperceel gekoppeld aan het beslag.
uri Periode 1 De periode waarin beslag gelegd is op een gebruiksperceel door een exploitatie.

Gebruiksperceel

Beschrijving
Een perceel dat gebruikt is voor een bepaalde toepassing.
Subklasse van
RuimtelijkeEenheid
Eigenschappen
Voor deze entiteit zijn de volgende eigenschappen gedefinieerd: identificator .
Eigenschap Verwacht Type Kardinaliteit Beschrijving Gebruik Codelijst
identificator Identificator 1 Identificatiecode van het Gebruiksperceel. Bijvoorbeeld: AGPAKEY.

Datatypes

Adresvoorstelling

Beschrijving
Meer leesbare voorstelling met enkel de basisgegevens van het adres, bedoeld voor het gebruik van een adres als attribuut van een ander object.
Gebruik
Bijvoorbeeld als attribuut van een persoon of gebouw, ... De adresvoorstelling heeft niet enkel betrekking op Belgische adressen, ze kan gebruikt worden om buitenlandse adressen weer te geven (waar mogelijk andere adresaanduidingen dan huisnummer of busnummer worden gebruikt of waar adrescomponenten zoals adresgebieden voorkomen).
Subklasse van
Locatie
Eigenschappen
Voor dit datatype zijn de volgende eigenschappen gedefinieerd: busnummer , gemeentenaam , huisnummer , land , postbus , postcode , straatnaam , volledigAdres .
Eigenschap Verwacht Type Kardinaliteit Beschrijving Gebruik Codelijst
busnummer String 0..1 Officieel toegekende alfanumerieke code die wordt toegevoegd aan het huisnummer om meerdere gebouweenheden, standplaatsen, ligplaatsen of percelen te onderscheiden die eenzelfde huisnummer hebben. Specialisatie van Adresvoorstelling:locatieaanduiding ten behoeve van Belgische adressen.
gemeentenaam LangString 0..1 Gemeentenaam van het adres.
huisnummer String 0..1 Alfanumerieke code officieel toegekend aan gebouweenheden, ligplaatsen, standplaatsen of percelen. Specialisatie van Adresvoorstelling:locatieaanduiding tbv Belgische adressen.
land LangString 0..1 Land waarin het adres gelegen is.
postbus String 0..1 Postbusnummer in een postkantoor.
postcode String 0..1 Code waarmee het geografisch gebied dat adressen voor postale doeleinden groepeert wordt aangeduid.
straatnaam LangString 0..1 Straatnaam van het adres.
volledigAdres LangString 0..1 Het complete adres in één string, al dan niet geformatteerd. Vermijdt fouten ten gevolge van het opsplitsen van een adres in zijn onderdelen. Geeft de voorgeschreven volgorde van de verschillende onderdelen weer.

Contactpunt

Beschrijving
Informatie zoals email, telefoon, adres die toelaat om iemand of iets te contacteren.
Gebruik
Bijvoorbeeld: een persoon of organisatie of dienstverlening... Mogelijke vormen van contact: bellen, mailen, etc.
Eigenschappen
Voor dit datatype zijn de volgende eigenschappen gedefinieerd: adres , email , telefoon .
Eigenschap Verwacht Type Kardinaliteit Beschrijving Gebruik Codelijst
adres Adresvoorstelling 0..1 Adres dat men kan aanschrijven of bezoeken.
email String 0..1 Email-adres waarnaar men kan mailen.
telefoon String 0..* Telefoonnummer waarop men kan bellen.

Identificator

Beschrijving
Informatie gebruikt om een object uniek te identificeren.
Gebruik
Uitgangspunt hier is dat deze string door een organisatie wordt toegekend en dat dit gebeurt volgens een welbepaald systeem.
Eigenschappen
Voor dit datatype zijn de volgende eigenschappen gedefinieerd: toegekendDoor , identificator .
Eigenschap Verwacht Type Kardinaliteit Beschrijving Gebruik Codelijst
toegekendDoor Agent 0..1 Link naar de agent die de identificator heeft uitgegeven.
identificator Literal 0..1 String gebruikt om het object uniek te identificeren. Type vd string slaat op het identificatiesysteem (incl de versie ervan), de string zelf op de eigenlijke identificator.
