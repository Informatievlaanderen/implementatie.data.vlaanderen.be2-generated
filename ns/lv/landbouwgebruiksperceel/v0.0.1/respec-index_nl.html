Definition Persoon waarvan de gegevens zijn ingeschreven in een register.
Label GeregistreerdPersoon
Usage note Doorgaans is dit register een bevolkingsregister maar het kan bv ook een kiesregister zijn. rechtspersoonlijkheid

URI https://implementatie.data.vlaanderen.be/ns/lv/landbouwgebruiksperceel#rechtspersoonlijkheid
Definition Geeft aan of de rechtspersoonlijkheid van de GeregistreerdeOrganisatie deze is van een natuurlijk persoon of van een rechtspersoon.
Label rechtspersoonlijkheid
UsageNote Een rechtspersoon is een juridische constructie die een organisatie dezelfde rechtspersoonlijkheid geeft als een natuurlijk persoon (kan bijvoorbeeld ook schulden hebben, contracten afsluiten, aangeklaagd worden, etc.). Voorbeelden privaatrechterlijke rechtspersonen: vennootschappen, vzw's, etc.; Voorbeelden publiekrechterlijke rechtspersonen: steden, gemeenten etc. Een feitelijke vereniging is in principe geen rechtspersoon maar wordt als ze geregistreerd is in KBO toch als dusdanig geklasseerd.
Domain http://www.w3.org/ns/regorg#RegisteredOrganization
Range http://www.w3.org/2004/02/skos/core#Concept
